## 💼 Professional Experience

### AI Engineer — Revenue Recovery Engine
*January 2026 – Present | Remote*

**Revenue Recovery Engine (RRE)**

- Co-developed an event-driven LLM pipeline that analyzes Shopify customer reviews, identifies gaps between product expectations and listings, and recommends evidence-grounded listing edits using Inngest and Supabase (PostgreSQL).
- Contributed to structured-output validation and developed internal human-annotation tools for reviewing and labeling AI-generated listing recommendations.

**Syntax Instruments**

- Co-developed a local-first desktop AI application for patent professionals using React, Tauri/Rust, and the Eve agent runtime, contributing across workspace workflows, tool integrations, and its migration to a Berd/Goose-based foundation.
- Led development of Search Workspace, enabling the AI agent to search and read PDF and DOCX documents using SQLite FTS5/BM25 full-text search and retrieve relevant passages.

### AI Engineer Intern — Beyond Apps Group
*June 2025 – July 2025 | Cairo, Egypt*

- Developed a second-generation AI ad creation workflow using LangGraph and FastAPI for [MyZesty](https://play.google.com/store/apps/details?id=com.myzesty), a mobile video-editing application with 500K+ Google Play downloads.
- Extended the existing short-video feature to support prompt-defined multi-scene advertisements, orchestrating image/video generation, duration-aware segmentation, continuity prompting, and final video stitching.
