## 🚀 Featured Projects

### 📊 [Retail Analytics Copilot (Agentic RAG & SQL)](https://github.com/YoussefMohamedym3/retail_analytics_copilot)
*   **Orchestration:** Built a LangGraph agent combining vector search + SQL generation using a local **Phi-3.5 (3.8B)** model via Ollama.
*   **DSPy Optimization:** Boosted SQL generation accuracy from **20% to 60%** (and system accuracy from **50% to 83%**) using DSPy's `BootstrapFewShot`.
*   **Self-Healing Loop:** Engineered a schema-aware SQL repair loop that autonomously corrected syntax errors, reducing run execution failures by **>70%**.

### 🎙️ [EduToons: AI-Driven Educational System](https://github.com/YoussefMohamedym3/EduToons)
*   **Voice Pipeline & Evaluation:** Fine-tuned RVC (Retrieval-Based Voice Conversion) models and curated custom voice datasets; benchmarked quality and performance in a dedicated [evaluation repository](https://github.com/YoussefMohamedym3/voice-conversion-evaluation).
*   **Integration:** Collaborated on pose tracking (MediaPipe) and Blender rigging (BlenderArMocap) to drive animations.
*   **Impact:** Field-tested in 3 kindergartens with children aged 5-10, achieving a **MOS of 4.1/5**.
